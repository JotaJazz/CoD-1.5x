CoD 1.5x - https://github.com/JotaJazz/CoD-1.5x

Requires Call of Duty multiplayer patched to 1.5 (original copy).

INSTALL / UPDATE
 1. Extract install.bat and cod15x.dll into your Call of Duty folder
 2. Double-click install.bat and choose 1
 3. Start multiplayer: the bottom-right corner shows "1.5x" and the build number

UNINSTALL
 Double-click install.bat and choose 2

Manual install: rename mss32.dll to mss32_original.dll, then copy cod15x.dll
as mss32.dll. Manual uninstall: delete mss32.dll, rename mss32_original.dll
back to mss32.dll.

If the game crashes, a report is saved in the "crashes" folder: please attach it
to an issue on GitHub.

Useful settings: r_mode 10 (native resolution), m_rawinput 0/1 (raw mouse),
r_borderless 1, cg_widescreenfov 0/1 (Hor+ FOV), cl_updatecheck 0/1,
cl_allowCustomDlls 1 (allow mod DLLs).
